# 🔑 طريقة الحصول على كود التحقق

بعض الحسابات والاشتراكات داخل فاندر تتطلب كود تحقق مؤقت لتسجيل الدخول مثل:

- Steam Guard
- OTP
- Verification Code
- Email Code

ويتم توفير الكود عبر:

- بوت تليجرام
- أو مركز التحقق الخاص بفاندر

حسب نوع المنتج الموضح داخل الطلب.

---

## 🤖 الحصول على الكود عبر بوت التليجرام

بعض المنتجات تعتمد على بوت تلقائي للحصول على الكود.

### الخطوات:

1. افتح رابط البوت المرفق مع الطلب
2. أدخل:
   - رقم الطلب
   - أو الكود الخاص بطلبك
3. اضغط على:
```txt
Get OTP Code
````

4. انتظر حتى يظهر الكود الخاص بالحساب.

---

## 🌐 الحصول على الكود عبر مركز التحقق

بعض المنتجات الجديدة تستخدم نظام التحقق الخاص بفاندر.

### الخطوات:

1. ادخل على مركز التحقق
2. أدخل كود الطلب أو رمز التفعيل
3. ستظهر لك:

   * معلومات الحساب
   * حالة الاشتراك
   * زر الحصول على الكود
4. بعد الضغط على زر الكود سيتم إنشاء كود تحقق مؤقت للحساب.

---

## ⏳ مدة صلاحية الكود

أغلب أكواد التحقق:

* مؤقتة
* تنتهي خلال دقائق
* تستخدم مرة واحدة فقط

لذلك يفضّل تجهيز صفحة تسجيل الدخول قبل طلب الكود.

---

## ⚠️ مهم جدًا

* لا تطلب أكثر من كود بدون حاجة
* لا تشارك الكود مع أي شخص
* بعض المنتجات تسمح بطلب الكود مرة واحدة فقط
* تكرار الطلبات بشكل عشوائي قد يؤدي إلى تأخير أو حظر مؤقت

---

## 🎮 حسابات Steam المشتركة

في حسابات Steam المشتركة:

* الكود يستخدم لتسجيل الدخول فقط
* لا تقم بتغيير المنطقة أو العملة
* لا تربط وسائل دفع مباشرة
* لا تستخدم الحساب على عدد أجهزة مخالف للتعليمات

---

## 🚨 واجهت مشكلة؟

إذا:

* لم يظهر الكود
* انتهت المهلة
* ظهر خطأ أثناء التحقق
* أو فقدت الوصول للحساب

تواصل مع الدعم مباشرة مع إرفاق:

* رقم الطلب
* صورة المشكلة
* اسم المنتج

وسيتم مساعدتك بأسرع وقت ممكن.
